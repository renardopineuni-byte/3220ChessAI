# 3220ChessAI
A 2 agent chess harness Both agents inherit from a parent ‘agent’ class that has an unimplemented chose agent function chose_move(board) returns a move to played given any valid board position

sniperAgent by Renardo Pine Focusing on maintaining distance with the queen bishop and rook while keeping pieces under attack

kingAgent by Khyana Panton Focuses on surrounding and attacking the enemy king

To play: Run chessboard.py and choose either Human (You) vs AI or AI vs AI. In Human vs AI, choose your color and AI opponent In AI vs AI, sniperAgent is white, kingAgent is black
